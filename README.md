# Стратегия HR-платформы · 2027–2029

Лендинг тестового задания Product Owner: привлечение и управление воронкой кандидатов, два сегмента найма, Discovery, образ будущего, продуктовые ставки, дерево метрик и роадмап.

Статический сайт без JavaScript, внешних зависимостей, аналитики и этапа сборки. Содержание — в `index.html`, оформление — в `style.css`.

Исходные воронки и сроки AS IS — условная модель. TO BE — целевые ориентиры кейса. Исследования описаны как план, а эффекты продуктовых решений требуют проверки.

## Локальный просмотр

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8765/.

В настройках репозитория открыть **Pages → Build and deployment → Deploy from a branch**. Выбрать ветку `main` и папку `/ (root)`, сохранить.
